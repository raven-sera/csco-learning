# 汇度 · MyCO（My CSCO）

[打开网站](https://raven-sera.github.io/csco-learning/)

从二合一入口进入 **MyCO**，检索 1,298 场会议内容、安排个人听会日程、记录笔记，并在个人图书馆统一查阅。另一入口保留为 CSCO 会议海报图鉴。

- 电脑使用固定左侧管理栏；手机通过左上角三横线打开同一导航，支持遮罩关闭、Escape 和键盘焦点管理。界面采用蓝紫渐变、磨砂玻璃、圆角卡片及不同的悬停／按下反馈，兼容减少动画设置。
- 左栏包含检索、收藏、我的日程、个人图书馆、图鉴，以及会场导航、打卡图鉴和导出资料。
- 检索首页只展示简明搜索台，支持时间、场地、单位（类型或具体单位）、领域和研究方向筛选。输入或筛选后展示结果，也可主动浏览全部报告。
- 原始内容的精确匹配始终在前；近似拼写和相关词匹配列于「相似选项」分割线后。切换会议时间排序也保持分组，跨页后的相似结果仍带分割提示。
- 学习页面提前准备，会场地图、笔记和导出功能按需打开。
- 日程、下一场与报告详情可查看会场；也可从会场会议列表增删日程。地图仅作静态位置对照，不提供实时定位或步行路线。
- 个人图书馆自动汇总当前浏览器中的文字笔记、PPT 照片和录音，支持检索批注、标签筛选及继续阅读。灵感海报模块已移除。
- PPT 支持连续拍摄、连续阅读、全屏缩放、重点页、批注、排序、扫描校正与跨报告移动；原图保留。
- 完整笔记 PDF 用于阅读；图书馆 ZIP 备份用于恢复文字、原图、扫描版、录音、批注和阅读位置。导入会先校验，再明确选择保留或替换冲突报告。
- 收藏、日程、笔记、照片、录音和打卡仅保存在当前浏览器，不随源码公开上传，不自动跨设备同步。
- 互动游戏入口已移除。会议海报图鉴尚缺正式地址，入口与左栏明确标注未接入；与已有个人打卡图鉴区分，不提供虚构海报。

`main` 分支更新后，GitHub Actions 自动构建、检查并部署网站。

本地构建、SSH 上传及数据保留说明请见 [发布说明](README-GITHUB.md)。
