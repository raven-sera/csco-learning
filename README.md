# 汇度 · MyCO（My CSCO）

[打开网站](https://raven-sera.github.io/csco-learning/)

从二合一入口进入 **MyCO**，检索 1,298 场会议内容、安排个人听会日程、记录笔记，并在个人图书馆统一查阅。另一入口保留为 CSCO 会议海报图鉴。

- 品牌统一为「Dotnet汇度｜医界望远镜」；入口主标题为「从这里，看医界，无边界」，英文为「where there is knowledge, there is no edge.」。

- 电脑使用固定左侧管理栏；手机通过左上角三横线打开同一导航，支持遮罩关闭、Escape 和键盘焦点管理。界面以深海军蓝／钴蓝为主色，珊瑚橙／亮黄作点缀，白色／冰蓝承托磨砂玻璃面板；保留背景模糊、渐变融合、圆角卡片及不同的悬停／按下反馈，兼容减少动画设置。
- 界面主题不覆盖资料内容：笔记自选文字色、高亮、下划线、PPT 原图和会场原图保持原样。
- 左栏包含检索、收藏、我的日程、个人图书馆和独立的打卡图鉴；会场导航与导出资料保留在会议工具区。
- 检索首页只展示简明搜索台，支持时间、场地、单位（类型或具体单位）、领域和研究方向筛选。输入与选择筛选只修改草稿，点击搜索或按 Enter 后才展示结果；结果页再次修改条件也需重新提交。中文输入法确认候选字不会触发搜索，也可主动浏览全部报告。
- 原始内容的精确匹配始终在前；近似拼写和相关词匹配列于「相似选项」分割线后。切换会议时间排序也保持分组，跨页后的相似结果仍带分割提示；收藏的紧凑卡片逐项标示相似匹配，不占用额外报告位置。
- 收藏顶部采用紧凑搜索区，每页 12 场（末页按实际数量），桌面卡片和手机摘要行按屏幕高度分配，不需要纵向滚动浏览本页报告。手机保留标题、报告人和时间，长标题省略显示，点击可查看完整信息；筛选、批量加入日程、导出及取消本页收藏保留。
- 我的日程默认展示全部日期的紧凑 TO-DO 清单，一屏排列多条报告，按实际可用高度分页，不纵向滚动；左侧圆圈用于现场打卡。日历采用 iOS 式日期条与真实时间轴，桌面可切换单日／三日，手机按天查看；事件按实际起止时间定位、重叠时并排显示，通过日期与 30／60／120 分钟时段切换浏览。长标题及短事件可从「本时段」列表查看完整信息。冲突筛选与更多操作保留；PDF／ICS 导出始终包含全部日程，不受当前日期、时段和分页限制。
- 学习页面提前准备，会场地图、笔记和导出功能按需打开。
- 日程、下一场与报告详情可查看会场；也可从会场会议列表增删日程。地图保留立体、原图及 1F／2F／总览，不再提供俯视模式；仅作静态位置对照，不提供实时定位或步行路线。
- 个人图书馆以书架汇总当前浏览器中的文字笔记、PPT 照片和录音：真实 PPT 缩略图或题目封面、独立阅读／编辑入口、继续阅读与已保存页码，手机双列展示。批注检索、标签筛选和备份功能保留。
- 本场笔记统一使用单一主区：PPT、文本、录音点击切换。桌面在右侧保留缩略入口，手机使用顶部紧凑卡；PPT 显示当前页缩略图，文本显示摘要，录音显示录制／保存／授权状态。切换保留编辑历史与阅读位置，不中断录音。
- PPT 支持连续拍摄、连续阅读、全屏缩放、重点页、批注、排序、扫描校正与跨报告移动；原图保留。
- 文本笔记使用 Word 式字体色、高亮和下划线分体按钮，支持主题／标准／最近颜色、自定义色值、移除格式与撤销重做；打开颜色面板仍保留选区。
- 打卡图鉴使用已有打卡记录绘制山东大厦楼层分布与打卡先后连线，统计总次数、各会场次数、会议日和听会关键词。点击会场或关键词可筛选报告；同场只计一次，移出日程不删除打卡。未知位置仍计入统计，不虚构坐标或实际行走路线。
- 完整笔记 PDF 用于阅读；图书馆 ZIP 备份用于恢复文字、原图、扫描版、录音、批注和阅读位置。导入会先校验，再明确选择保留或替换冲突报告。
- 收藏、日程、笔记、照片、录音和打卡仅保存在当前浏览器，不随源码公开上传，不自动跨设备同步。
- 互动游戏入口已移除。二合一首页中的独立会议海报入口仍因缺少正式地址标注未接入；MyCO 左栏已改为可使用的「打卡图鉴」，不再提供未接入的海报侧栏项。
