# 汇度 · CSCO 互动学习

[打开网站](https://raven-sera.github.io/csco-learning/)

从三合一入口进入 CSCO 会议学习台，检索 1,298 场会议内容、安排个人听会日程、保存笔记和现场灵感。

- 适配手机与电脑，重新打开时先进入统一入口。
- 学习页面提前准备，文献按报告加载，笔记和导出功能按需打开。
- 收藏、日程、笔记、录音和打卡保存在当前浏览器，不随源码公开上传。
- 互动游戏与海报图鉴目前为待接入入口。
