2. 把源码放在仓库根目录，连同隐藏的 `.github` 文件夹一起上传；不要上传 `node_modules`、本地备份或个人笔记。
3. 在仓库的 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
4. 上传到 `main` 或 `master` 分支后，**Actions → Publish CSCO to GitHub Pages** 会构建并发布。若之前因尚未开启 Pages 失败，在开启后重新运行该工作流。
5. 等待发布步骤成功，再打开上述网址。后续推送代码会自动更新网站。

如果使用 SSH 上传，先把本机 SSH 公钥添加到 GitHub，再验证：

```powershell
ssh -T git@github.com
```

成功消息应包含 `Hi raven-sera!`。GitHub 不提供 SSH shell，因此成功认证后返回退出码 1 是正常现象。SSH 可上传代码，创建仓库与首次 Pages 设置仍在网页中完成。

## 本地构建

需要 Node.js 22.13 或以上。

```powershell
npm ci
npm run test:paths
npm run test:search
npm run test:venues
npm run test:calendar
npm run test:timeline
npm run test:attendance
npm run build:github
```

静态网站生成在 `out` 文件夹。发布工作流会自动识别账号和仓库路径；本地默认使用上述目标。若改名，通过 `GITHUB_REPOSITORY=账号/仓库` 指定，或设置 `NEXT_PUBLIC_BASE_PATH` 和 `NEXT_PUBLIC_SITE_ORIGIN`。

GitHub 构建使用已安装的 Next 静态导出，无须 Cloudflare Worker、ChatGPT 登录、数据库或付费服务器。构建过程会检查六条页面路由、资源路径和二合一入口。原始项目中的 `npm run build` 仍用于旧版托管；GitHub 发布必须使用 `npm run build:github`。

## 加载速度

- 入口首屏显示后，空闲时提前加载学习台；鼠标悬停或键盘聚焦入口也会准备页面。省流模式、离线和 2G 网络跳过这项后台加载。
- 打开地图后才加载地图组件、图面数据与本地 Three.js 引擎；入口与报告列表不预载立体地图。原图仅在切换原图或降级显示时加载。
- 立体地图按交互和尺寸变化绘制，不持续空转；关闭时释放 WebGL、事件监听和尺寸观察器。引擎加载失败或图形连接中断时，自动切换到可点选的原图。

## 会场地图与数据边界

- 从日程清单、日历、手机端“我的下一场”或报告详情进入地图；选中会场后可查看当天会议，并加入或移出日程。
- 目前覆盖山东大厦一、二层原图中的 36 个具名区域。手工轮廓、体块高度与入口参照不代表实测尺寸、真实门位或用户当前位置，不推断步行路线及楼层连接。
- 同名空间按楼层区分；“海右泺源厅”同时标出海右厅、泺源厅，并明确提示分隔及门位待核。泰安厅、中泰证券厅标为位置待核，不猜测匹配；南郊宾馆会场保留会议与日程功能，但不虚构室内地图。
- 手机使用“会场地图／当天日程／找会场”分屏，支持双指缩放、点选和可展开的图纸说明；电脑保留左右分栏、鼠标操作及键盘选择。
- “引用与延伸阅读”模块及其文献下载、构建数据已删除；原有笔记、录音、收藏、日程、打卡与导出数据不迁移、不清空。

## 打卡图鉴

- `/atlas` 直接读取已有打卡记录，每场报告只计一次；重复点击仅重新打开打卡卡片。移出或清空日程不删除已经完成的打卡。
- 按会场规范名称统计次数，归并“一楼／一层”别名；合并会场按一个场地计数，同时标出已有的多个图面区域。会议日根据报告日期统计。
- 按实际打卡时间绘制相邻会场之间的示意弧线。暂无地图或位置待核的会场仍进入统计与听会足迹，但不产生虚构坐标，也不跨过这些中间站拼接路线。
- 关键词来自源日程表的报告题目与癌种，同场同词只计一次，不宣称分析未提供的报告全文。点选会场或关键词可组合筛选并打开对应报告。
- 支持双层总览、单层查看、缩放和地图内横向滚动；地图不代表步行路线、真实距离或楼层连通关系。原有打卡语保留在折叠收藏区。

## 个人图书馆与本场笔记

- 左侧栏的「个人图书馆」统一汇总个人资料，手机通过三横线展开同一导航。日程的「记笔记／继续记录」直接打开本场文本，「拍 PPT」打开当前报告的照片来源选择。
- 有效文字、PPT 照片或录音保存后自动出现在图书馆；仅收藏、仅排期不产生空白资料。移除日程不删除个人资料。旧 IndexedDB 笔记及历史 localStorage 文本均可读取。
- 支持搜索报告、讲者、文字笔记、PPT 批注与标签；按内容类型、日期、癌种或标签筛选，并保留列表筛选及滚动位置。图片文字不提供 OCR 搜索。
- 封面使用已保存 PPT 的真实缩略图；没有照片时使用报告题目、癌种和讲者，不生成虚构封面。电脑多列、手机双列；点击封面阅读，点击「编辑」增补内容，较多笔记分批展示。
- Word 式文字格式工具提供字体色、高亮与带颜色的下划线，支持主题／标准／最近颜色、自定义色值、自动／移除及撤销重做。混合格式有状态提示，颜色面板支持键盘操作并保留原选区，不向保存内容插入选区装饰。
- 手机和电脑均使用单一笔记主区，点击 PPT／文本／录音切换，其余内容保持缩略入口。文字默认只读，明确进入编辑后自动保存。正在录音、存在保存失败或未完成照片处理时，离开笔记会受保护。
- PPT 默认连续阅读，支持缩略图目录、页码跳转、重点页筛选和全屏缩放翻页，按照片 ID 恢复阅读位置。批注按需展开；文字中的「引用当前 PPT」使用固定照片 ID，排序后不串页，跨报告移动后仍定位到该照片，删除后明确提示失效。
- 「管理」提供多选、拖动及按钮排序、选中照片扫描、旋转／手动校正、跨报告移动和确认后批量删除。移动保留原图、扫描版、批注与重点标记。
- PPT 的「拍摄 / 添加」仅保留「系统拍照」「从相册添加」两个来源，空白照片区使用相同入口。「系统拍照」调用带后置拍摄提示的系统文件输入，实际相机界面由设备和浏览器提供，电脑端可能显示文件选择窗口；「从相册添加」支持多选。取消选择不改变已有照片，选定后的导入与错误提示仍在照片区完成。
- 「扫描选中」尝试识别较亮的 PPT 四边，进行透视校正与适度亮度／色彩整理。暗色主题、反光、遮挡或边缘不明确时可能跳过；可在「旋转 / 手动校正」中拖动四角或用方向键微调。自动结果仍需检查，不具备 OCR 或恢复模糊文字的能力。
- 原图始终保留，扫描版单独保存；可逐张选择原图或扫描版，选择只影响展示和导出，不覆盖原文件。
- 「完整笔记 PDF」包含完整报告信息、文字、按当前顺序和所选版本展示的 PPT、批注／重点标记与录音清单。PDF 不包含可播放的音频。照片区的「生成 PDF／生成 PNG 图片包」保留照片专用导出，不含文字批注；PNG ZIP 内仍是封面与编号图片。文件生成后再点击下载。
- 单张图片上限 40 MB、4800 万像素、单边 16384 像素；扫描和导出长边最多 2400 像素，原文件不缩小。HEIC／HEIF 仅在浏览器原生支持解码时可用，不支持时请转 JPEG 或 PNG。
- 笔记、照片与录音保存在当前浏览器，不上传服务器或 GitHub，不自动跨设备同步。清理站点数据、结束无痕会话或浏览器回收存储可能造成丢失。请遵守会议拍摄和资料使用规定。
- 数据库升级保留原笔记、照片、录音，并建立不含原图与音频的检索索引及缩略图缓存。若升级被其他页面阻塞，请关闭其他 CSCO 标签页后重试。

## 完整备份与恢复

- 图书馆「备份 / 恢复」生成 ZIP，包含文字 HTML、原图／扫描版／缩略图、录音原文件、照片 ID 与顺序、批注、重点标记、标签和阅读位置。备份不加密，必须保存在自己的安全位置，不应提交到公开仓库。
- 导入先校验清单版本、文件结构、体积、类型和校验码，再显示报告、照片、录音数量及冲突。损坏文件不会写入。只保留安全且受支持的富文本格式、内嵌栅格图片与链接。
- 默认按整场报告保留本机内容、跳过冲突报告。选择整场替换时必须再次勾选确认；该报告本机独有的文字、照片、录音和标签也会被替换。写入使用单个事务；跨报告资料 ID 冲突会阻止恢复，避免覆盖未选报告。
- 当前 ZIP 上限 512 MiB、展开总量 1 GiB、单个二进制文件 128 MiB，超限会明确报错。PDF 与 PNG 导出只是阅读留存文件，不能恢复完整编辑状态。

## 二合一入口与原有数据

- 打开首页即进入二合一。新开、刷新检索、收藏、日程、图书馆或打卡图鉴页面时，先回统一入口，随后可继续目标页面、报告及指定照片位置。
- GitHub Pages 网站可以公开访问；旧站的平台访问控制不会随静态文件迁移。
- 笔记、PPT 照片、录音、收藏、日程和打卡按浏览器与域名分别保存，不会自动跨域转移，也不会随源码上传到 GitHub。
- 新版本可通过图书馆 ZIP 备份与恢复转移个人学习资料。迁移旧版本时仍应导出其笔记、PPT 图集、日程文件并下载录音；旧版 PDF/图片不是可恢复备份。日程、收藏和打卡不属于图书馆 ZIP 内容，需分别保留。
- 旧站和本地备份均可保留；确认资料留存和新站可用后，再调整对外分享的网址。
